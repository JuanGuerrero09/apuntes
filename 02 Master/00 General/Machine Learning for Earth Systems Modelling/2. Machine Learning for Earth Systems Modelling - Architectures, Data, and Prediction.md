### Introduction to Deep Learning

Deep learning is a subfield of machine learning that uses algorithms inspired on the structure and functions on the brain, specifically on the neurons (ANN - Artificial Neural Networks)

### Overview of ML architectures in weather and climate
Architectures are basically shape and configuration of layers in neural networks
Some of them are:
- Unets: A neural network architecture that is classically used in image segmentation tasks. In Weather and Climate science these are for instance used to classify storm or cloud types. (Encoder - Bottleneck - Decoder)
- ResNet: A deep neural network architecture that uses skip connections (residual connections) to make very deep networks easier to train. ResNets are well suited for image classification while the U-Nets are used for image segmentation.
- Graph Neural Networks (GNN): A neural network architecture that operates on data structured as a graph, where nodes (data points) are connected by edges, allowing relationships (e.g. spatial connections) between points to be explicitly modelled.
- Recurrent Neural Networks: A neural network architecture that is designed to process sequential data. In Weather and Climate science these were the first models used to predict time series from historical data.

### Terminology

#### Neural network terminology

- Neuron: The basic unit of a neural network, which takes a weighted sum of its inputs, adds a constant (called bias), and passes the result through a (non-linear) activation function.
- Wight matrix: A matrix of the network’s “learnable parameters”, which defines the strength of the individual connections between two layers. The weights are tuned during training.
- Activation function: A non-linear function applied to a neuron's output, allowing the network to learn patterns beyond linear combinations.
- Dense layer: A layer in which every neuron is connected to every neuron in the previous layer.
- Multi-layer perceptron: A feedforward neural network with one or more hidden dense layers between the input and output, capable of learning non-linear relationships.


#### Neural network training

- Forward pass: The process of passing input data through the network layer by layer to produce a prediction.
- Loss Function: A function that measures the discrepancy between the network's predictions and the target truth, providing the signal that training tries to minimise.
- Backward pass: The process of computing gradients of the loss with respect to each weight by propagating the error signal back through the network using the chain rule.
- Gradient descent: An optimisation algorithm that iteratively updates weights in the direction that most reduces the loss, as indicated by the gradients.
- Batch: A subset of the training data processed together in one forward and backward pass, with weight updates applied after each batch.
- Learning Rate: A scalar that controls how large a step is taken in the direction of the gradient during each weight update.
- Epoch: One complete training pass through the entire training dataset.


#### Techniques to improve training

- Input/Output normalization: Scaling input and output data to a standard range (e.g. 0–1 or zero mean, unit variance). This is necessary because all features in dense neural network layers will connect to all other variables, so if some features have large values (e.g. temperature in Kelvin) and some have small values (e.g. precipitation rates in mm/s), the large ones will dominate training.
- Layer normalization: Normalising the output of all activation functions within a layer, or a set of layers. This helps stabilise training, especially in deep or so-called “recurrent” and “transformer” networks.
- Batch normalization: Normalising activations across a batch of data for each feature. This tends to reduce sudden shifts in the relationships of such a feature (e.g. a temperature pattern), and that tends to make higher learning rates possible.
- Dropout: Randomly setting a fraction of neurons to zero during each training step, forcing the network to learn redundant representations. This really helps to reduce overfitting.

### Why Convolutional Neural Networks for Images?

In previous sessions, you utilized fully connected neural networks, also known as Multi-Layer Perceptrons (MLPs). While powerful, MLPs face two significant limitations when processing image data.

#### Parameter Explosion

Images are composed of high-dimensional data. For a standard 28x28 grayscale image: input features. If a single hidden layer contains 100 neurons, the model requires weights for just that layer. For modern high-definition images, the number of parameters becomes computationally prohibitive and leads to rapid overfitting.

#### Lack of Spatial Awareness

Flattening an image into a 1D vector destroys the spatial relationships between pixels. If a digit shifts by just a few pixels, the resulting vector changes drastically. The model would then need to learn the same feature (like a curve or an edge) separately for every possible location in the image.

#### The CNN Solution

CNNs utilize two fundamental concepts to solve these issues:

1. **Local Connectivity:** Instead of every neuron connecting to every pixel, filters (kernels) look at small local regions (e.g., 3x3).
2. **Weight Sharing:** The same filter is slid across the entire image. This allows the model to detect the same feature regardless of its position, drastically reducing the parameter count.
### Convolution versus MLP

MLP scales poorly with image sizes and use a inefficient weight use.

CNN architecture leads to smaller neural networks

### Terminology

- Inductive Bias: The set of assumptions built into a model's architecture that guide it toward certain solutions, e.g. CNNs assume spatial locality and pattern repetition.
- Translation equivalence: The property that shifting the input spatially produces a correspondingly shifted output, i.e. a CNN should detect features regardless of where they appear in the image.
- Input size: The spatial dimensions (height × width) and number of channels of the feature map (e.g. an image) fed into a convolution layer.
- Kernel Size: The height and width of the small filter of trainable weights that slides across the input.
- Stride: The step size by which the kernel moves across the input, which controls how much the output is downsampled.
- Padding: Extra values (typically zeros or ones) added around the border of the input so that the kernel can be applied at the edge.
- Channels: The depth dimension of a feature map, where each channel can try to learn a different aspect of the feature map.
- Pooling: A downsampling operation (e.g. max or average) that summarises local regions of a feature map.
- Residual/Skip Connections: Shortcuts that add a layer’s output to the input of a layer far downstream in the network, so gradients from the loss to early layers in very deep networks remain direct. This helps smooth the loss landscape.
